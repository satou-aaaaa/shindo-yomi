# 震度よみ（shindo-yomi）

揺れの様子（人の感じ方・部屋の中・外・建物・地盤）を見て、気象庁の解説表でその様子が書かれている震度（0〜7）を当てる1日5問の学習ゲーム。正解したら「まちで起きることがあるのは？」（鉄道・ガス・エレベーターなどが止まる目安）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/shindo-yomi/>

- 中身は気象庁「気象庁震度階級関連解説表」（<https://www.jma.go.jp/jma/kishou/know/shindo/kaisetsu.html>）と「震度について」（<https://www.jma.go.jp/jma/kishou/know/shindo/index.html>）に書いてあることだけです。
- 解説表は「その震度で起きることがある様子」で、様子から震度を決めるものではありません。同じ震度でも、建物や地盤で被害は変わります。
